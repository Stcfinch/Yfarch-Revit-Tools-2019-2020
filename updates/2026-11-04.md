# v2026.11.04｜Revit 2019／2020 穩定版

此版本以同一套原始碼分別編譯 Revit 2019 與 2020 外掛。安裝程式可選擇目標版本；兩版都要使用時，請各安裝一次。

## 主要更新

- 功能列改為「永豐工坊」，各功能加入圖示，分組名稱改為繁體中文。
- 「視圖裁切」可依參考平面設定全棟與分區，並建立或更新從屬視圖。
- 「視圖命名」提供中文圖名、圖號編排與重排。
- 「自動圖紙化」新增「圖紙修正定位」：從專案已載入的圖框族與型別偵測外框和可放區，不必先建立空白圖紙。放置視圖時依實際 Viewport 外框左右置中，以下方可見圖框線為基準預留 3 cm；同一主視圖的從屬視圖會使用相同圖框型別。
- 結構樑加入鋼構樑生成與細部尺寸表配對等功能。

## 使用順序

1. 如需分區，先執行「視圖裁切」。
2. 執行「視圖命名」，確認中文圖名與圖號。
3. 第一次使用專案圖框時，在「自動圖紙化」選擇「圖紙修正定位」，勾選要偵測的圖框型別並核對結果。
4. 再選擇「自動放圖紙」，預覽圖紙配置後執行。

圖框自動偵測依賴族內可辨識的水平與垂直邊線；若偵測失敗或可放區不符合預期，請先檢查圖框族線條與偵測結果。外掛不會自動儲存 RVT，完成後請自行儲存專案。

## 安裝

關閉 Revit，下載 Release 的 `Yfarch-Revit-Tools-2019-2020.zip`，解壓後執行安裝程式。選擇 Revit 2019 或 2020，完成後重新開啟對應版本。
