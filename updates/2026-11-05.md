# v2026.11.05｜自動圖紙化定位更新

此版本更新 Revit 2019 與 2020 的自動圖紙化。安裝程式可選擇目標版本；兩版都要使用時，請各安裝一次。

## 更新內容

- 視圖大小與排版依「編輯裁剪」的 CropBox 判斷，減少網格及註解超出裁剪範圍時對位置的影響。
- 圖框定位採用空白區真正的下緣，避免將標題欄內部線誤認為底線。既有本機圖框定位設定會在讀取時換算。
- 底排每張視圖的裁剪下緣各自距空白區底線 3 cm。程式比較不同分排與圖框的可放空間；多排視圖依設定間距排列，2×2 等每排張數相同的排法以最寬一排決定共同左緣。
- 試放後檢查整組 Viewport 的實際上緣。若超出空白區上緣，撤回並改試下一排法或圖框；所有候選都不合適時才保留置中位置。Viewport 外框超出偵測可放區會在報告中提示。
- 已放到圖紙上的視圖仍會略過，重新編排前請先移除原有 Viewport。

## 安裝

關閉 Revit，下載本版本的 `Yfarch-Revit-Tools-2019-2020.zip`，解壓後執行安裝程式並選擇 Revit 2019 或 2020。外掛不會自動儲存 RVT；完成後請自行儲存專案。
